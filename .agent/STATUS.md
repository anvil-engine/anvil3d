# Status

Milestone: M3 Renderer + M5 movement foundation — in progress. `+map d1_trainstation_01` loads the BSP, mounts its pakfile, draws world geometry (base textures, lightmaps, displacements with WorldVertexTransition blend), 2D sky, brush entities and static props with PVS + frustum culling; Jolt walking player by default, optional noclip. ## Working
- Weapon scripts: bounded parsers load original `scripts/weapon_manifest.txt` and WeaponData identity, view/world model, animation prefix, ammo and SoundData fields. Installed HL2 validates 18/18 scripts through ordered VFS; 17 available viewmodels expose 339 bind-pose bones, 140 sequences and 139 animations/4850 frames, while two authored model references are missing/invalid and reported. Weapon behavior and frame pose decoding remain unsupported.
- VGUI fonts: FreeType loads original CustomFontFiles bytes through VFS and scans bounded platform font directories for exact authored family/style matches (no nearest-family substitution). Faces select real Unicode glyphs through scheme fallback/range rules and rasterize grayscale/mono coverage with original metrics. Installed ClientTitleFont/HALFLIFE2.ttf U+0041 and SourceScheme Default/Verdana text validate. Proportional scaling, style effects, reusable atlases and full text layout remain unsupported.
- VGUI text foundation: strict bounded UTF-8 single-line layout composes original glyph coverage and metrics into an RGBA8 texture plus a backend-neutral `Batch2D` quad. Kerning/shaping, line wrapping, accelerators, effects and reusable atlases remain unsupported.
- VGUI panel resources: original control type/name, localized label/title, command, visibility/enabled/default state, tab order and bounded geometry are interpreted. Observed `cN` center, `rN` far-edge position and `fN` fill extents resolve against parent bounds. Installed NewGameDialog and OptionsSubKeyboard resources validate.
- VGUI control runtime: Panel/EditablePanel/Frame, Label, Button and Divider descriptors instantiate with resolved local bounds. Visible/enabled Button controls receive authored default/tab focus, wrap in both directions and accept keyboard or mouse activation. The diagnostic executes `Close`, `ResumeGame`, `Quit` and `engine ...`; every other authored command is reported unsupported. Unknown game-specific controls stay present as Unsupported.
- VGUI paint path: Scheme Borders aliases and bounded Left/Top/Right/Bottom layers resolve in authored order with their colors and offsets. Basic controls produce authored background fills, Button/focus borders and text requests; fills/borders batch together, while each current text run owns an RGBA8 texture, alignment and control clip. Installed NewGameDialog uploads all 3 visible localized text runs through exact system Verdana. Unsupported controls remain visible in diagnostics.
- VGUI schemes: literal RGB[A], Colors/BaseSettings aliases with bounded cycle detection, ordered font candidates filtered by inclusive yres/Unicode ranges (numbered or direct font definitions), ordered CustomFontFiles virtual paths. Authored font parameters remain untouched; no face substitution/rasterization or proportional scaling. `vgui_scheme <path> <font> <height>` exercises this through the engine. Synthetic regression cases and all font definitions/colors in installed SourceScheme/ClientScheme tested at five heights.

Headless Vulkan verifies authored fill/left/bottom colors by pixels; installed NewGameDialog and OptionsSubKeyboard data pass. Include-model animation indices are preserved but unresolved; no frame pose decoding/flex/bodygroups yet.
- devui/: optional Dear ImGui overlay (`-DANVIL_DEVUI=ON`, run with `-devui`), drawn via render::2d; ImGui textures via RendererHasTextures.
- render/: backend-neutral Device (textures, frames, draw2d, caps, headless readPixels). render/vulkan: MoltenVK/native via volk, portability enumeration/subset, swapchain resize/out-of-date, deferred destruction, 2D pipeline. Verified: Apple M4 (MoltenVK, Vulkan 1.1.323) windowed + headless; llvmpipe (Linux) headless under Khronos validation: no messages.
- materials/texture: VTF -> render::TextureData (mips, BC1-3 kept or decoded, other formats -> RGBA8). All 5237 HL2 textures convert on both paths (`vtf_hl2`).
- render: TextureFormat RGBA8/BC1/BC2/BC3, mip chains, clamp/repeat samplers; DeviceOptions::forceUncompressedTextures. VMA for all Vulkan memory.
- render: 3D path — static meshes (Vertex3D: pos, uv, lightmap uv), Draw3D = texture * lightmap * scale (Opaque/AlphaTest/Translucent), depth buffer (reverse Z), column-major viewProj with y-up clip space.
- world/: BSP -> world::Mesh (fan-triangulated faces, displacement grids, texture + lightmap UVs, shelf-packed RGBA8 lightmap atlas), grouped per material. World: loads maps/<name>.bsp, mounts pakfile {GAME,BSP} at head, resolves VMT -> VTF -> device textures (missing = magenta checker), LightmappedGeneric-style drawing. All 78 HL2 maps build (CPU); d1_trainstation_01 renders headless and windowed (`world_hl2`, 0 missing assets).
- world/visibility: per-frame PVS (camera leaf -> cluster -> decompressed PVS) + frustum (face bounds vs 5 planes) -> visible faces merged into per-material index ranges. Displacements (never in leaf face lists in HL2) get clusters from their bounds pushed down the node tree. Counters: faces / PVS / frustum / submitted / triangles / draws (`r_worldstats`); `r_novis 1` = frustum only. d1_trainstation_01 spawn: 6678 faces -> 1352 PVS -> 126..643 submitted over 4 view directions; images identical with PVS on/off (`world_hl2`).
- world/entities: brush entities ("model" "*N") as placement-only runtime objects: Transform (origin + angles -> local-to-world), world bounds, PVS clusters. Brush models share the world's vertex/index buffer and lightmap atlas (world::Mesh covers every model, batches per model + material) and draw through the same draw3d path with viewProj * transform. Draw order: opaque world, opaque entities, translucent world, translucent entities. trainstation_01: 50 drawn brush entities; train car (func_tracktrain) visually correct on its tracks.
- WorldVertexTransition: displacement painted alpha -> Vertex3D::blend; Draw3D::texture2 = $basetexture2, blended in the shader (mix by vertex weight). Direction (alpha 255 = $basetexture2) checked on HL2 data: rock-layer-weighted triangles are steep (mean 0.60) vs soil-weighted (0.16) over all rock/soil WVT displacements; d2_coast_03 visually plausible.
- Static props: formats/bsp parses per-leaf ambient light (LDR/HDR index + samples, validated). world/props loads each prop model (studio LOD 0 default body) into one shared prop mesh; World places instances (Transform from origin/angles), culls by prop leaf clusters (PVS), transformed bounds (frustum) and fademaxdist (hard cull, no fade), resolves materials through the material dirs + skin family, tints each prop with the nearest leaf ambient sample (lighting origin / bounds centre / origin). 18545 HL2 props: 98.3% get an ambient sample; trainstation_01: 300 props, 0 missing; visually placed correctly (tracks, roof trusses, lamps, benches).
- world/sky: 2D skybox from worldspawn `skyname` (materials/skybox/<name>{rt,ft,lf,bk,up,dn}; `_hdr` names use their LDR $basetexture, fallback to the name without `_hdr`), drawn first with Blend::Background and a translation-free view; $basetexturetransform scale/center/translate applied. Face layout derived from HL2 data (texture seams + sun direction). 77 of 78 maps resolve all 6 faces; `intro` names sky_trainstation01, which has no materials (WARN).
- engine: `map <name>` command; `anvil.cfg` + `+commands` run after renderer init; optional free camera via noclip (RMB look, WASD, Space/Ctrl, Shift), `sensitivity` cvar; platform input (keys by SDL name, mouse buttons, relative motion).
- engine: renders every frame (clear + world + devui); flags -norender, -novsync, -vkdebug.
- Tests: cmdline, keyvalues, filesystem, console(+clock), interfaces (real module load), smoke (tests/data/testgame).

- cvar flags (cheat/archive), config.cfg saving, autocomplete, in-game console UI.
- Simulation ticks consumed by independent Jolt walking runtime; retail client/server game code still not loaded.
- World render gaps (logged STUB/PARTIAL at runtime): Water/Refract surfaces not drawn; WorldVertexTransition ignores $blendmodulatetexture / $basetexturetransform2 (WARN); other shaders drawn as LightmappedGeneric; no 3D skybox (sky_camera); sky faces are not drawn (sky shows through them, nothing hides geometry behind them); brush entities drawn at their spawn placement only (no movement, StartDisabled, rendermode/renderamt, parenting); render-target textures (_rt_*, func_monitor) not drawn; decals, overlays, detail props not drawn; static props lit by one ambient cube average per prop (no direct light, no per-vertex/VHV lighting: darker than Source), no LODs/bodygroups, dx level gating only; lightmap style 0 + flat samples only (no bump, no switchable lights); translucent draws unsorted; RGBA16161616F textures clamped to RGBA8 (WARN).
